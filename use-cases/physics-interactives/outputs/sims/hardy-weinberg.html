What to notice

With both selection sliders at zero and N infinite, the trace is perfectly flat — forever, at any starting p. A can be the dominant allele and still sit at 0.05 for a thousand generations. Dominance decides which phenotype you see; it has nothing to do with which allele gets commoner.

The solid bars and the dashed outlines separate the instant you add selection. Dashed is what Hardy–Weinberg predicts from the current p; solid is what survived. The gap is the selection.

Frequency only moves when you break an assumption. There are two here: selection (the sliders) and finite population size (drift). Each looks different — selection is a smooth slide, drift is a stagger.

Try this

  1. Before touching anything else: set starting p to 0.10 and press Run. A is dominant. Predict what happens to p over 100 generations, then watch. Explain the flat line to someone next to you.
  2. Set selection against aa to 1.00 — lethal recessive, nobody with aa reproduces. Start at p = 0.50 and run. Does q reach zero? Step through the last few generations one at a time and read the aa frequency. Why does purging get so slow?
  3. Set both selection sliders to 0.30 — heterozygote advantage. Start at p = 0.90, run; then reset, start at p = 0.10, run. Where does p end up each time?
  4. Return both sliders to zero and set N to 25. Run it three times from p = 0.50. Same rules, same start — do you get the same answer? Now try N = 1000.
  5. With N = 25 and no selection, run until p hits 0 or 1. Once it does, can it ever come back? What assumption would you have to restore to let it?

Model limitations

One locus, two alleles, non-overlapping generations, and random mating with no mutation and no migration. Real populations violate all of these at once, which is why real allele frequencies are hard to attribute to a single cause.

Fitness here is a fixed number attached to a genotype. In a real population fitness depends on density, on environment, and on what the rest of the genome is doing — and it changes from year to year.

Drift is modelled by drawing 2N alleles at random each generation. That captures the sampling idea correctly but treats every individual as equally likely to reproduce, which no field population does.
