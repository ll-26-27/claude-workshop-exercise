Class summarizer / file guide

This example converts a workshop transcript into ten key takeaways in Markdown and HTML. Read summary.md for the workflow and limitations.

Top-level

  • summary.md — purpose, workflow, and limitations
  • index.md / index.html — this file

inputs/

Session transcripts. One markdown file per day, with speaker tags.

  • day_1_transcript.md — Day 1 of the workshop
  • day_2_transcript.md — Day 2 of the workshop
  • day_3_transcript.md — Day 3 of the workshop; no summary has been generated

operations/

  • key-takeaways-prompt.md — the reusable distillation prompt. Forces exactly 10 takeaways with bold one-sentence headlines, an italic provenance opening, and a secondary-points section
  • operations/skills/
    • md-to-deepthoughts-html/ — converts a markdown takeaways doc into a self-contained "Deep thoughts" style HTML page (cream/serif Dario layout, Newsreader font, screen + mobile + print styles, Print and Copy MD buttons)

outputs/

One markdown and one HTML per session.

  • day-1-key-takeaways.md / .html
  • day-2-key-takeaways.md / .html

To process another session, add its transcript to inputs/, apply the takeaways prompt, review the result, and then run the HTML conversion skill.
