Day 3 — Top 10 Key Takeaways

Short summary of the Day 3 transcript.

  1. Start each session in the correct project folder. Clone or download the repository, then open a session with that folder selected.
  2. Use git pull to update a clone. A ZIP download does not provide the same update path.
  3. Search for existing repositories. They may contain useful texts, data, scripts, or methods.
  4. Treat public repositories as untrusted inputs. Check owners, licenses, files, and scripts before using them.
  5. Keep large files separate from working text. Connect to large media and datasets deliberately.
  6. Use a clear project folder. Keep inputs, operations, and outputs together.
  7. Skills package repeated operations. They define expected inputs, steps, and outputs.
  8. Project instructions provide shared context. A CLAUDE.md file can document structure and checks.
  9. Use templates for consistent documents. A text source can be turned into a reusable layout.
  10. Review generated work and permissions. Check the source, plan, changes, and final output before approving actions.

Secondary points

  • Model names and limits change; check current settings.
  • Keep sensitive data out of prompts and repositories.
  • Inspect strange results before retrying.
