# Operations

The main operation is the
[`handout-formatting` skill](../.claude/skills/handout-formatting/SKILL.md). Its
folder contains the workflow, reference documents, build script, and LaTeX style
files.

The skill remains under `.claude/skills/` so Claude Code can find it when this
project folder is opened. See [`../summary.md`](../summary.md) for the workflow
and [`../CLAUDE.md`](../CLAUDE.md) for project-specific instructions.
