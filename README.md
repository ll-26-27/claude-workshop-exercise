# Claude workshop

A one-day workshop on working with Claude through files and folders rather than
only a chat window. Bok Center · Learning Lab.

## What's here

| Folder | What it holds |
|---|---|
| [`_workshop-exercise/`](_workshop-exercise/) | The exercise the room does together. Photos of each table's AI-comfort spectrum in, a coded CSV and an interactive chart out. |
| [`_workshop-use-case/`](_workshop-use-case/) | Five worked examples to take away, each one a complete project you can copy and repoint at your own material. |
| [`resources/`](resources/) | A 30-term glossary and nine print-ready handouts, plus setup guides for Mac and Windows. |

## The shape everything follows

```
inputs/       what you start with
operations/   the prompts, skills, and scripts that do the work
outputs/      what you end up with
```

The exercise uses it. Every use case uses it. The
[recipe-card handout](resources/handouts/recipe-card.html) is one page on why.

## Getting set up

If you have not installed Claude Code yet, start with
[`resources/handouts/setup-checklists/`](resources/handouts/setup-checklists/) —
there is a printable checklist for Mac and one for Windows, plus a longer guide
that explains what each step is for.
